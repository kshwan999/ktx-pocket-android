# KTX 자리찾기 — 안드로이드 개인 설치용

계속 화면을 보고 있기 어려울 때, 원하는 조건의 KTX 빈자리를 찾아 예약을 시도하는 안드로이드 개인용 앱입니다.
컴퓨터나 별도 서버를 켜둘 필요 없이 휴대폰에서 로그인·조회·예약을 실행합니다. 예약된 승차권의 결제는 코레일톡에서 직접 해야 합니다.

## 주요 기능

- **빈자리 자동 검색**: 출발역·도착역·날짜·시간·인원·좌석 종류를 정해 검색합니다.
- **여러 대안 함께 확인**: 날짜·시간이나 출발역이 다른 조건을 최대 3개까지 차례로 확인하고, 예약 1건을 확보하면 검색을 끝냅니다.
- **이동 시간을 고려한 출발역 대안**: 각 역까지 걸리는 시간을 입력하면 추가 이동 허용 범위와 승차 여유를 고려해 후보를 고릅니다.
- **예약 결과와 결제 재알림**: 예약 결과를 알리고, 결제 기한을 확인하도록 다시 안내합니다.
- **입력 정보 기억**: 최근 검색 조건을 기억하며, 원하는 경우 아이디와 비밀번호도 휴대폰에 암호화해 저장합니다.

코레일 통신에는 `pykorail` 라이브러리를 사용합니다. 텔레그램 봇이나 별도 데이터 저장 서버(Redis)는 필요하지 않습니다.

## 아이폰용 시험 버전

[아이폰 개발 안내](ios/README.md)에서 iOS 26 이상용 실행 시험 프로젝트를 확인할 수 있습니다. 현재는 조건 입력·이동 시간에 따른 대안 계산·백그라운드 실행 간격 측정·결과 알림을 구현한 단계이며, **아이폰에서 실제 코레일 조회·예약은 아직 실행하지 않습니다.** 아래 설치 파일과 예약 기능 설명은 안드로이드 버전 기준입니다.

## 0.4.0 변경 사항

- **이동 시간을 고려한 다른 출발역 검색**: ‘다른 출발역도 찾아보기’를 켜고 같은 출발지에서 각 역까지 걸리는 시간을 직접 입력합니다. 현재 출발역을 포함해 1~3개 역을 등록하며, 현재 출발역까지의 시간 + 추가 이동 허용 시간 안에 드는 역만 후보가 됩니다. 예를 들어 서울 20분, 수서 50분, 추가 이동 허용 30분이면 두 역을 포함합니다. 예시 시간은 실제 경로 계산값이 아닙니다.
- 기본값은 추가 이동 허용 30분, 역 도착 후 승차 여유 15분입니다. 역까지의 이동 시간은 빈칸에서 시작합니다. 추가 이동 허용을 0분으로 설정하면 기준역보다 빠르거나 같은 역만 추가됩니다. 이동·추가 허용은 0~360분, 승차 여유는 0~120분입니다.
- 현재 조건과 직접 등록한 날짜·시간 대안을 우선하고, 남은 자리에 이동 시간이 짧은 출발역을 추가합니다. 자동 대안은 현재 조건의 도착역·날짜·시간 범위·인원·좌석 종류를 사용합니다. 전체 검색 조건은 최대 3개이며, 모든 조건의 출발역에 이동 시간을 등록해야 합니다. 확인 창에 나온 조건만 고정해 검색하며 1건 예약 후 전부 종료합니다.
- 허용 이동 시간을 넘거나 현재 시각에 이동 시간·승차 여유를 더했을 때 종료 시간 전에 도착할 수 없는 조건은 제외합니다. 검색 중에도 도달 가능한 가장 빠른 출발 시각을 계속 갱신합니다. 좌석 발견 후와 통신 대기 후에도 예약 요청을 보내기 전에 다시 검사합니다. 전송 전에 시간이 부족해지면 해당 예약 요청을 보내지 않습니다. 실제 교통·통신 지연으로 승차 가능성을 보장하지는 않습니다.
- 예약 성공 메시지에 확보한 출발역과 입력한 이동·승차 여유 기준으로 이동을 시작해야 하는 시각을 표시합니다.
- 역 이동 시간과 활성화 여부는 휴대폰 안에 기억하며 ‘역 이동 시간 설정 초기화’로 지웁니다. 역 이름을 수정하면 해당 이동 시간을 비워 잘못 재사용하지 않게 합니다. 최근 검색에는 직접 입력한 조건을 저장하고 자동 대안은 다음 검색 시작 시 다시 계산합니다. 로그인 정보와 별도로 저장합니다.
- 기본 상태는 꺼짐이며, 위치 추적·지도 경로 계산·실시간 교통·도착역에서 최종 목적지까지의 이동·전체 도착 시간 최적화는 포함하지 않습니다. 수서 등 개별 역의 실제 조회 지원 여부, 새 화면 배치와 실제 예약은 기기에서 별도 확인이 필요합니다.

## 0.3.0 변경 사항

- 따뜻한 흰색 바탕, 차콜 글자, 테라코타 오렌지 포인트로 색상·글자·아이콘·입력창을 정리했습니다.
- 검색 상태와 진행 표시를 위에, **시작·중지 버튼을 화면 아래에 고정**했습니다. 예약 후 결제 확인과 재알림 끄기는 상태 카드에 표시합니다.
- 출발·도착역을 나란히 묶고 역 바꾸기 버튼을 추가했습니다. 날짜·시간은 구분된 선택 칸으로 표시하며 시스템 글자 크기 설정을 따릅니다.
- 여행 조건·대안 목록·코레일 계정·알림 설정을 접어서 볼 수 있습니다. 검색 중에는 입력 영역을 접고 조건 요약을 표시하며, 다시 펼쳐 확인할 수 있습니다. 저장된 아이디와 비밀번호가 모두 있으면 계정 영역은 처음에 접혀 있습니다. 로그인 정보가 필요하면 검색 버튼에서 해당 입력란을 펼칩니다.
- 검색·예약 엔진, 암호화 저장, 알림 예약 방식은 이전 버전과 같습니다. 기능 검사는 통과했으나 실제 휴대폰의 화면 배치와 큰 글자·키보드 표시 상태는 별도 확인이 필요합니다.

## 0.2.0 변경 사항

- **최근 검색 조건 기억**: 검색 시작 시 역·날짜·시간·인원·좌석 종류와 추가한 대안을 기억하고 다음 실행에 자동 입력합니다. 지난 날짜를 임의로 바꾸지 않으므로 수정하거나 지난 대안을 삭제한 뒤 시작하세요. 로그인 정보와 별도로 저장하며, ‘기억한 검색 조건 지우기’로 삭제합니다.
- **여러 대안 감시**: 현재 입력 조건과 추가 대안 2개, 최대 3개를 차례로 조회합니다. 현재 조건과 동일한 대안은 중복 조회하지 않습니다. 먼저 예약되는 **1건**만 확보하고 모든 조건의 검색을 종료합니다. 조건을 병렬 조회하지 않으며, 모든 요청은 기존 3~5초 대기를 공유합니다.
- **결제 재알림**: 성공 알림에 이어 약 1분 후, 서버가 알려준 결제 기한 약 5분 전에 다시 알립니다. 두 시점이 가깝거나 기한이 임박하면 한 번만 알립니다. 기한을 읽지 못하면 1분 후 재알림만 예약하고 기한을 임의로 정하지 않습니다.
- 결제·취소 여부는 자동 확인하지 않습니다. 확인 후 앱 또는 알림의 **‘결제·취소 확인 · 재알림 끄기’**를 눌러주세요. 이전 예약의 재알림을 끄기 전에는 새 검색을 시작하지 않습니다. 이 버튼은 실제 결제나 취소 요청을 보내지 않습니다.
- **검색 중단 알림**: 통신 오류·접속 제한·실행 한도·모든 출발 시간 경과를 알립니다. 수동 중지는 별도 결과 알림을 울리지 않습니다. 프로세스가 사라진 경우 저장된 실행 상태를 로컬 알람으로 보조 확인하며, 발견하면 알리고 자동 예약은 재개하지 않습니다.
- 재부팅 후에는 이전 검색 중단과 남아 있는 예약 확인을 안내하고, 아직 지나지 않은 결제 재알림을 복원합니다. 검색을 자동 재시작하지 않습니다.
- **알림 설정**: ‘예약 결과 알림 설정’에서 소리·진동을 확인하고, 안드로이드 12 이상에서는 ‘결제 재알림 시간 설정’에서 알람 및 리마인더 권한을 허용할 수 있습니다. 권한이 없으면 부정확한 알람으로 예약합니다. 절전·알림 차단·강제 중지·재부팅 등에 따라 알림이 늦거나 오지 않을 수 있으므로 기한 내 알림을 보장하지 않습니다. 강제 중지나 전원이 꺼진 동안에는 앱이 스스로 알릴 수 없습니다.
- 최근 검색 조건, 알림용 예약 결과·결제 기한·실행 상태는 이 휴대폰의 앱 내부에 저장하고 백업에서 제외합니다. 알림은 추가 코레일 조회 없이 로컬에서 처리하며, 로그인 정보는 기존 선택형 암호화 저장만 사용합니다.

## 0.1.3 변경 사항

- 앱 설명과 라이선스 화면에서 직접 구현한 안드로이드 앱과 사용한 라이브러리를 구분해 표기합니다.
- `pykorail` 저작권·라이선스 전문과 비상업적 이용 조건은 유지합니다. 검색·예약 동작에는 변경이 없습니다.

## 0.1.2 변경 사항

- 모든 코레일 HTTP 요청은 이전 요청이 끝난 뒤 최소 대기 시간을 **3~5초 사이에서 무작위로 선택**합니다. 로그인·조회·예약 요청 모두 같은 제한을 사용합니다. 오류 대기나 처리 시간에 따라 실제 간격은 더 길어질 수 있습니다.
- 조회 통신 오류나 일시적 조회 실패가 이어지면 **30초 → 60초 → 120초 → 120초**로 대기하고, 5회 연속 실패하면 중지합니다. 정상 조회가 되면 오류 대기를 초기화합니다.
- 접속 제한 응답과 HTTP 403·429에는 자동 재시도하지 않습니다. 예약 결과가 불확실할 때도 기존처럼 중지합니다.
- 오류 대기 중에도 검색 중지 버튼을 사용할 수 있습니다.
- 이 변경은 요청을 분산하고 오류 시 부하를 줄이기 위한 것으로, 매크로 탐지나 차단을 피한다고 보장하지 않습니다.

## 0.1.1 변경 사항

- **아이디 기억**: 선택하면 다음 실행에서 최근 입력한 아이디를 자동 입력합니다.
- **비밀번호도 기억**: 선택하면 최근 입력한 비밀번호도 자동 입력합니다. 아이디 기억이 함께 선택됩니다.
- 선택한 정보는 ‘확인하고 검색 시작’을 눌렀을 때 저장합니다. 입력값을 기억하는 기능이므로 로그인 성공 여부와는 별개입니다.
- 저장 값은 안드로이드 보안 키 저장소(Android Keystore)가 관리하는 키로 AES-256-GCM 암호화하며, 서버나 깃허브로 전송하지 않습니다. 로그인 시 코레일로 전달하는 기존 동작은 같습니다.
- 비밀번호 기억을 해제하면 저장된 비밀번호를 지웁니다. **저장된 로그인 정보 지우기**로 아이디와 비밀번호를 모두 지울 수 있습니다.
- 저장 정보 삭제는 이미 실행 중인 검색을 멈추거나 앱의 기기 식별자를 바꾸지 않습니다.
- 암호화/복원에 실패하면 평문 저장으로 대체하지 않으며 안내 문구를 표시합니다. 앱 데이터 삭제 또는 재설치 후에는 다시 입력해야 합니다.

## 현재 확인 범위

- 이 앱은 개인 테스트용입니다. 실제 기기의 코레일 로그인과 예약 성공은 별도 확인이 필요합니다.
- 코레일 로그인·조회·예약 통신에 `pykorail 0.5.1`을 사용합니다.
- 컴퓨터용 통신 모듈인 `curl-cffi` 대신 안드로이드의 암호화 통신 연결과 인증서 저장소를 사용합니다. 이 변경이 코레일 서버에 허용되는지는 실제 기기에서 확인해야 하며, 로그인 성공을 보장하지 않습니다.
- 안드로이드 8 이상, 64비트 ARM 기기를 대상으로 합니다.

## 사용 방법

1. 개인 테스트용 설치 파일을 휴대폰으로 옮겨 설치합니다. 필요한 경우 해당 파일 앱의 ‘알 수 없는 앱 설치’를 허용합니다.
2. 앱의 알림 권한을 허용합니다. 집 와이파이 사용을 권장합니다.
3. 코레일 로그인 정보와 출발/도착역, 날짜, 시간 범위, 어른 인원, 좌석 종류를 입력합니다.
4. 다른 날짜·시간도 괜찮다면 현재 조건을 ‘대안 목록에 추가’한 뒤 입력란을 다른 조건으로 바꿉니다. 확인 창에 나온 최대 3개 조건 중 먼저 예약되는 1건만 확보합니다.
5. 다른 출발역도 괜찮다면 ‘다른 출발역도 찾아보기’에서 역별 이동 시간을 입력하고 기능을 켭니다. 현재 출발역을 포함해 등록하고, 추가 이동 허용 시간과 승차 여유를 정합니다. 지도 앱 등에서 실제 이동 가능 시간을 직접 확인해 입력해주세요.
6. 확인 창에 나온 역·시간·인원·좌석 조건을 확인한 뒤 검색을 시작합니다. 예약 성공 알림이 오면 코레일톡의 예약내역에서 결제 기한을 확인하고 직접 결제합니다. 결제·취소를 확인했으면 재알림을 꺼주세요.
7. 앱이나 진행 알림의 ‘검색 중지’로 멈출 수 있습니다. 이미 보낸 예약 요청은 결과 확인까지 시간이 걸릴 수 있습니다.

기억 옵션을 선택하지 않은 로그인 정보는 파일에 저장하지 않습니다. 기억을 선택한 정보만 암호화해 앱 내부 저장소에 보관하며, 백업과 다른 기기로의 복사에서 제외합니다. 암호화 키를 APK나 파일에 넣지 않습니다. 기기 식별자는 앱 내부 저장소에 유지합니다. 앱 데이터 삭제/재설치로 식별자가 바뀔 수 있습니다.

## 이용 조건과 제한 사항

- 개인용만 허용합니다. 상업적 이용, 유료 예매 대행, 전매 용도로 사용할 수 없습니다.
- 모든 코레일 HTTP 요청 사이에 3~5초의 무작위 최소 대기를 두며, 3초 미만으로 줄이는 설정은 없습니다.
- 집 와이파이 사용을 권장합니다. 데이터센터나 가상 사설망(VPN)의 인터넷 주소는 접속이 제한될 수 있으며, 모바일 데이터 환경은 검증되지 않았습니다.
- 접속 제한 응답이나 HTTP 403·429가 오면 자동 재시도하지 않습니다.
- 예약 요청 중 통신 오류 등으로 결과가 불확실하면 중지합니다. 코레일 예약내역을 먼저 확인한 뒤 다시 시작해야 합니다.
- 안드로이드의 실행 제한을 고려해 1회 검색을 최대 5시간 45분으로 제한합니다. 운영체제·제조사 절전 정책·강제 종료·재부팅으로 더 일찍 종료될 수 있으며 자동 재개하지 않습니다.
- 성인 1~6명, KTX 직통, 한 번에 예약하는 방식만 포함합니다. 다인 인접 좌석, 임의 분할 예약, 환승, 자동 결제는 지원하지 않습니다.
- 코레일의 비공식 통신 방식을 사용하므로 코레일 변경이나 접근 정책에 따라 동작이 멈출 수 있습니다.
- 공개 앱스토어에 배포하거나 외부 서버를 공개하는 작업은 하지 않았습니다.

## 개발자를 위한 앱 만들기

개발 도구로 JDK 17 이상, 안드로이드 개발 도구 모음(Android SDK) 35, Gradle 8.13, 앱을 만드는 데 사용할 파이썬(Python) 3.13이 필요합니다.

```powershell
.\gradlew.bat -PbuildPython=C:/path/to/python.exe :app:assembleDebug :app:lintDebug
```

명령의 `C:/path/to/python.exe`는 설치된 파이썬 실행 파일 경로로 바꿔주세요. 앱을 만드는 데 사용하는 파이썬은 앱에 포함되는 파이썬과 같은 3.13 계열이어야 합니다. `local.properties`에 컴퓨터의 안드로이드 개발 도구 경로를 설정합니다. `--no-deps`는 `pykorail`의 컴퓨터용 통신 패키지를 제외하기 위한 설정이며, 앱이 사용하는 안드로이드용 암호화 패키지는 `app/build.gradle`에 명시했습니다.

자동 검사 실행:

```powershell
python -m unittest discover -s tests -v
.\gradlew.bat -PbuildPython=C:/path/to/python.exe :app:testDebugUnitTest
```
