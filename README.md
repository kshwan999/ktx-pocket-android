# KTX 자리찾기 — 안드로이드 개인 설치용

Android 화면과 검색 실행 흐름을 직접 구현한 개인용 앱입니다. 코레일 통신에는 `pykorail` 라이브러리를 사용하며, PC 없이 휴대폰에서 로그인, KTX 조회, 예약 시도를 실행합니다.
텔레그램 토큰, Redis, 별도 서버는 사용하지 않습니다. 결제는 코레일톡에서 직접 합니다.

## APK 다운로드

[개인 테스트 APK 받기](https://github.com/kshwan999/ktx-pocket-android/releases/tag/v0.1.3-test)

릴리스의 Assets에서 `KTX-Pocket-0.1.3-test.apk`를 받으면 됩니다. 저장소가 비공개인 동안에는 접근 권한이 있는 GitHub 계정으로 로그인해야 합니다.
기존 앱 위에 업데이트 설치할 수 있습니다. 업데이트는 실행 중인 검색을 종료할 수 있으므로 먼저 검색을 중지하고, 진행 중인 예약 요청이 있다면 코레일 예약내역을 확인해주세요.

## 0.1.3 변경 사항

- 앱 설명과 라이선스 화면에서 직접 구현한 Android 앱과 사용한 라이브러리를 구분해 표기합니다.
- `pykorail` 저작권·라이선스 전문과 비상업적 이용 조건은 유지합니다. 검색·예약 동작에는 변경이 없습니다.

## 0.1.2 변경 사항

- 모든 코레일 HTTP 요청은 이전 요청이 끝난 뒤 최소 대기 시간을 **3~5초 사이에서 무작위로 선택**합니다. 로그인·조회·예약 요청 모두 같은 제한을 사용합니다. 오류 대기나 처리 시간에 따라 실제 간격은 더 길어질 수 있습니다.
- 조회 통신 오류나 일시적 조회 실패가 이어지면 **30초 → 60초 → 120초 → 120초**로 대기하고, 5회 연속 실패하면 중지합니다. 정상 조회가 되면 오류 대기를 초기화합니다.
- 접속 제한 응답과 HTTP 403·429에는 자동 재시도하지 않습니다. 예약 결과가 불확실할 때도 기존처럼 중지합니다.
- 오류 대기 중에도 검색 중지 버튼을 사용할 수 있습니다.
- 이 변경은 요청을 분산하고 오류 시 부하를 줄이기 위한 것으로, 매크로 탐지나 차단을 피한다고 보장하지 않습니다.

## 0.1.1 변경 사항

- **아이디 기억**: 선택하면 다음 실행에서 최근 입력한 아이디를 자동 입력합니다.
- **비밀번호도 기억**: 선택하면 최근 입력한 비밀번호도 자동 입력합니다. 아이디 기억이 함께 선택됩니다.
- 선택한 정보는 ‘확인하고 검색 시작’을 눌렀을 때 저장합니다. 입력값을 기억하는 기능이므로 로그인 성공 여부와는 별개입니다.
- 저장 값은 Android Keystore가 관리하는 키로 AES-256-GCM 암호화하며, 서버나 GitHub로 전송하지 않습니다. 로그인 시 코레일로 전달하는 기존 동작은 같습니다.
- 비밀번호 기억을 해제하면 저장된 비밀번호를 지웁니다. **저장된 로그인 정보 지우기**로 아이디와 비밀번호를 모두 지울 수 있습니다.
- 저장 정보 삭제는 이미 실행 중인 검색을 멈추거나 앱의 기기 식별자를 바꾸지 않습니다.
- 암호화/복원에 실패하면 평문 저장으로 대체하지 않으며 안내 문구를 표시합니다. 앱 데이터 삭제 또는 재설치 후에는 다시 입력해야 합니다.

## 현재 확인 범위

- 이 앱은 개인 테스트용입니다. 실제 기기의 코레일 로그인과 예약 성공은 별도 확인이 필요합니다.
- 코레일 로그인·조회·예약 통신에 `pykorail 0.5.1`을 사용합니다.
- 데스크톱용 curl-cffi 대신 Android HTTPS 연결과 인증서 저장소를 사용합니다. 이 변경이 코레일 서버에 허용되는지는 실제 기기에서 확인해야 하며, 로그인 성공을 보장하지 않습니다.
- 안드로이드 8 이상, 64비트 ARM 기기를 대상으로 합니다.

## 사용

1. 개인 테스트용 디버그 APK를 휴대폰으로 옮겨 설치합니다. 필요한 경우 해당 파일 앱의 ‘알 수 없는 앱 설치’를 허용합니다.
2. 앱의 알림 권한을 허용합니다. 집 Wi-Fi 사용을 권장합니다.
3. 코레일 로그인 정보와 출발/도착역, 날짜, 시간 범위, 어른 인원, 좌석 종류를 입력합니다.
4. 조건을 확인한 뒤 검색을 시작합니다. 좌석이 나오면 실제 예약 요청을 합니다.
5. 예약 성공 알림이 오면 코레일톡의 예약내역에서 결제 기한을 확인하고 직접 결제합니다.
6. 앱이나 진행 알림의 ‘검색 중지’로 멈출 수 있습니다. 이미 보낸 예약 요청은 결과 확인까지 시간이 걸릴 수 있습니다.

기억 옵션을 선택하지 않은 로그인 정보는 파일에 저장하지 않습니다. 기억을 선택한 정보만 암호화해 앱 내부 저장소에 보관하며, 백업과 다른 기기로의 복사에서 제외합니다. 암호화 키를 APK나 파일에 넣지 않습니다. 기기 식별자는 앱 내부 저장소에 유지합니다. 앱 데이터 삭제/재설치로 식별자가 바뀔 수 있습니다.

## 제약

- 개인용만 허용합니다. 상업적 이용, 유료 예매 대행, 전매 용도로 사용할 수 없습니다.
- 모든 코레일 HTTP 요청 사이에 3~5초의 무작위 최소 대기를 두며, 3초 미만으로 줄이는 설정은 없습니다.
- 집 Wi-Fi 사용을 권장합니다. 데이터센터·VPN IP는 접속이 제한될 수 있으며, 모바일 데이터 환경은 검증되지 않았습니다.
- 접속 제한 응답이나 HTTP 403·429가 오면 자동 재시도하지 않습니다.
- 예약 요청 중 통신 오류 등으로 결과가 불확실하면 중지합니다. 코레일 예약내역을 먼저 확인한 뒤 다시 시작해야 합니다.
- Android의 실행 제한을 고려해 1회 검색을 최대 5시간 45분으로 제한합니다. 운영체제·제조사 절전 정책·강제 종료·재부팅으로 더 일찍 종료될 수 있으며 자동 재개하지 않습니다.
- 성인 1~6명, KTX 직통, 한 번에 예약하는 방식만 포함합니다. 다인 인접 좌석, 임의 분할 예약, 환승, 자동 결제는 지원하지 않습니다.
- 비공식 API이므로 코레일 변경이나 접근 정책에 따라 동작이 멈출 수 있습니다.
- 공개 앱스토어에 배포하거나 외부 서버를 공개하는 작업은 하지 않았습니다.

## 빌드

JDK 17 이상, Android SDK 35, Gradle 8.13, 빌드용 Python 3.13이 필요합니다.

```powershell
.\gradlew.bat -PbuildPython=C:/path/to/python.exe :app:assembleDebug :app:lintDebug
```

빌드용 Python은 SDK에 포함되는 Python과 같은 3.13 계열이어야 합니다. `local.properties`에 로컬 Android SDK 경로를 설정합니다. `--no-deps`는 pykorail의 데스크톱 HTTP 의존성을 제외하기 위한 것이며, 앱이 사용하는 Android용 암호화 의존성은 `app/build.gradle`에 명시했습니다.

검사:

```powershell
python -m unittest discover -s tests -v
.\gradlew.bat -PbuildPython=C:/path/to/python.exe :app:testDebugUnitTest
```
